# 11. Відомі обмеження

Те, що вже відомо: **не заводьте на це помилки**, але, якщо поведінка відрізняється від описаної, повідомте.

## Ніколи не перевірялось у реальних умовах

- **Push-сповіщення на справжньому телефоні** (закрита програма, заблокований екран). Усю цепочку (ключі, шифрування, підписки) перевірено лише автоматичними тестами. Результат вашого тестового сповіщення ([07](07-spovishchennia.md)) це перша реальна перевірка. Запишіть модель, систему, браузер, чи пришло.
- **Біометрія на реальних телефонах і комп'ютерах** (відбиток, обличчя, екран блокування).
- **Встановлення програми на пристрій** (PWA) на iPhone та різних Android.
- **Робота звіту без мережі** на справжньому пристрої при перериванні зв'язку.
- **Windows-файл на «чистому» комп'ютері** за політик антивірусів (SmartScreen, перевірка розпакованого cloudflared).
- **Самооновлення** в справжній роботі.
- Підпис файлу для Windows: крок є в процесі випуску, але ще не використовувався.

## Обмеження, які задумані

- **Біометрія потребує https** і постійного імені сайту. Тимчасова адреса `trycloudflare.com` змінюється при кожному запуску, тож ключі після перезапуску перестануть діяти (потрібен іменований тунель). Паролем можна завжди скористатись.
- Ключ доступу це **додатковий спосіб входу, а не другий фактор**: пароль далі працює окремо.
- **Лічильник невдалих входів** живе в пам'яті й обнуляється при перезапуску програми.
- **Авто блокується на 2 години**; військове замовлення не знімає авто з іншого військового й з того, що вже «В дорозі».
- **Вхід прив'язаний до браузера**: скопійований cookie в іншому браузері не працює.
- Надіслані звіти, до появи підписів, не показують, хто їх надіслав.
- Усе, що ви змінюєте в звіті без мережі, зберігається лише в цьому браузері; на сервер воно потрапляє після того, як ви збережете чернетку при наявній мережі.
- **Відновлення з резервної копії** вручну (замінити файл бази).
- **Одна програма, одна база**: SQLite у складі програми, без окремого сервера; призначено для невеликої команди.
- Windows-файл **не підписаний**; антивірус може реагувати на вбудований `cloudflared`.
- На **Android (Termux)** вбудований cloudflared не знаходить DNS: потрібен `pkg install cloudflared`.
- Нагадування лише одне: про відсутнє замовлення на завтра. Нагадувань про замовлення на сьогодні чи про незакриті диспетчеру немає.
- **Нових дозволів для продукції й рейсів немає**: використовуються дозволи транспорту ([06](06-produktsiia-i-reisy.md)).
- Інтерфейс лише українською.
- Збірка з GitHub **сама оновлюється**, якщо не вимкнути `AUTO_UPDATE=0`.
