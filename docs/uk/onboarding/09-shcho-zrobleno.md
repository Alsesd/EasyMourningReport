# 9. Що вже зроблено

Три позначки: **зроблено** (працює і покрито автоматичними тестами), **частково** (працює, але має відомі прогалини або не перевірене в реальних умовах), **не зроблено**. Автоматичні тести не замінюють ручну перевірку: саме її від вас чекають.

Стан на 7 листопада 2026. Рядки про транспорт будуть оновлені після завершення фази 2.
