# Migration risks

Each entry is marked **Fact** (verified in source or by probe), **Assumption** or **Open** (needs a decision or more evidence).

| # | Risk | Status | Mitigation |
|---|---|---|---|
| R1 | **Production DB shape differs from a fresh DB.** Legacy migrations built it with ALTER/RENAME; DDL text and column order differ. | Fact | Go never rebuilds tables. It creates only missing tables, from DDL taken from a fresh Python DB. A test compares `table_info`/`index_list`/`foreign_key_list` across a Go-fresh, a Python-fresh and a Python-migrated-legacy DB. |
| R2 | **Legacy-schema upgrades.** `platform.0001`, `reports.0001` and `reports.0002` convert pre-module databases. | Open | Recommended: Go does not port them. If any of the 3 ids is missing it refuses to start, with a message to run the last Python release once. Needs confirmation that every production DB has run the current Python release (Q3). |
| R3 | **Session cookie format.** itsdangerous TimestampSigner (HMAC-SHA1, django-concat key derivation). | Fact | Recommended: do not reimplement it. Cut over with a new signed cookie under the same name and secret, which forces one re-login. Old cookies fail verification and return 401, which the SPA handles by showing the login page (`AuthContext.tsx`). Decision Q4. |
| R4 | **Password hashes** must keep verifying. | Fact | Go 1.24 `crypto/pbkdf2` with SHA-256 and 200k iterations, format `salthex$hashhex`. Golden test: Python-made hashes verify in Go and the reverse. |
| R5 | **Audit `ts` has no timezone.** It is stored and served as naive UTC, and the browser shows it as local time, so it displays 2–3 h early in Ukraine. | Fact (existing bug) | Default: reproduce byte-for-byte. Fixing it (append `Z`) is a behaviour change. Decision Q5. Go must write the same text format into the DB either way. |
| R6 | **Money rounding.** Python Decimal uses half-to-even; comma decimals and spaces are accepted. | Fact | Port it as integer and string parsing with explicit half-even. Table tests: `0.125→12`, `0.135→14`, `"25,50"`, `" 1 000.5"`, `1e2`, negative values, `NaN`, values above 10^9. |
| R7 | **XLSX import differences.** openpyxl `data_only` returns cached formula values; Python `str()` of float cells; bool cells; dates; row numbering; header detection. | Fact (behaviour); Assumption (excelize parity) | Build a fixture corpus: real customer files (if available) plus synthetic ones (formulas, floats like 0.1+0.2, integer cells, text prices with commas, empty rows, header variants, merged cells, multiple sheets with a non-first active sheet). Compare the Python and Go parse results. Note excelize `GetRows` returns formatted strings by default; use raw values. |
| R8 | **XLSX export.** Downstream users may rely on the layout. | Fact (layout); Open (who consumes it) | Compare cell values, number formats, sheet name, freeze pane and auto-filter range, not bytes. |
| R9 | **OpenAPI-generated frontend types.** `npm run gen:api` runs the Python app to dump OpenAPI. | Fact | Freeze the current `schema.d.ts` as the contract during the migration. Afterwards, either hand-maintain an `openapi.json` checked against Go, or keep the frozen file plus contract tests. Don't add a Go OpenAPI framework just for this. |
| R10 | **Sorting/collation.** SQL BINARY ordering and Python `casefold()` sorts are mixed. | Fact | Keep SQL ordering in SQL. Use `strings.ToLower` (matches casefold for Cyrillic; differs for ß and a few other characters). Fixtures with і/ї/є/ґ and mixed case. |
| R11 | **SQLite locking under Go concurrency.** Go handlers run truly in parallel; read-then-write transactions risk `SQLITE_BUSY`. | Assumption | One writer connection, or `BEGIN IMMEDIATE` for writes. `busy_timeout=30000`. Load test like ADR 0003 (50 stores saving + reviewers). |
| R12 | **DATETIME handling in modernc.** Automatic time parsing/formatting. | Assumption (reviewer) | Scan and bind strings. Verify in the skeleton slice. |
| R13 | **Lax JSON coercion.** Pydantic accepts `"1"`, `2.0`, `true` as ints. | Fact | The SPA never relies on it. Go returns 422; document this as an intentional difference. |
| R14 | **Backup consistency and naming.** Local-time names, one-second resolution, mtime skip logic, retention by name, verification. | Fact | Port 1:1 with `VACUUM INTO`. Handle a name collision. Tests: restore round trip, retention, skip-if-unchanged including WAL-only change, a corrupt copy is deleted. |
| R15 | **Shutdown durability.** Python checkpoints the WAL and takes a final backup on shutdown. | Fact | `signal.NotifyContext` (SIGTERM/SIGINT), then `http.Server.Shutdown`, stop the tunnel, checkpoint, backup. Docker already has `init: true`. On Windows, console close gives about 5 s and there are no POSIX signals: keep shutdown fast, and consider running as a Windows service. |
| R16 | **cloudflared child process.** Orphaned on parent crash; Windows cannot send SIGTERM. | Fact (Python has the same gap) | Linux: `Pdeathsig`. Windows: a Job Object with kill-on-close. Keep the metrics port `127.0.0.1:20241` and the state files. |
| R17 | **Windows journal-mode detection.** `/proc/mounts` is absent, so it always uses WAL, even on SMB or mapped drives. | Fact (parity gap) | Keep parity by default. Optionally detect UNC or remote drives. |
| R18 | **Windows packaging is undocumented.** The repo has no build pipeline. | Open (Q2) | The Go build is `GOOS=windows go build` with the SPA embedded. Data next to the exe with the `%LOCALAPPDATA%\LegkyiZvit` fallback (identical rules). Test on real Windows before cut-over. |
| R19 | **Client IP trust.** A spoofed `X-Forwarded-For` would bypass the rate limit and falsify audit IPs. | Fact | Honour XFF only when `RemoteAddr` is in `FORWARDED_ALLOW_IPS`. Test it. |
| R20 | **CSRF check depends on the `Host` header.** The Vite dev proxy keeps Host (`changeOrigin:false`). | Fact | Compare `Origin`'s host:port with `r.Host`, case-insensitively, exactly as Python does. |
| R21 | **SPA fallback precedence.** It must not mask `/api` or `/static` 404s. | Fact | Explicit tests for `/api/x`, `/api`, `/static/x` and deep links. |
| R22 | **`current_period()` uses server local time.** The container is UTC, so at a month boundary the "current month" flips at 02:00/03:00 Kyiv time. | Fact (existing behaviour) | Keep parity: `time.Now()` local and the same `TZ` in Docker. Flag to the user. |
| R23 | **Unbounded integers.** Python ints are unbounded; a quantity ≥2^63 currently fails with a 500 at insert. | Assumption | Go returns 422 on int64 overflow; document it. |
| R24 | **Coverage gaps before porting** (see migration-plan.md, "Must test first"). | Fact | Characterization suite first. |
| R25 | **The two runtimes touching one DB.** | Risk if done | Never run Python and Go against the same file at once. Cut over by stopping Python, taking a tagged backup, then starting Go. |
| R26 | **No stated driver for migrating.** ADR 0003 shows Python is fast enough. | Open (Q1) | Write down the reason (single exe, memory, maintenance) so success criteria are measurable. |
